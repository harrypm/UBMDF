# GUI

```
ubmdf gui [--tab firmware|devices|update|log] [--select <dv-version>] [--check-catalog]
```

## Tabs
- **Firmware:** every indexed bundle, flashable first, newest to oldest, with filter chips (All / Flashable / Inventories).
  - The detail card shows one line per image (part, size, erase blocks, write address), the source note and the manifest path.
  - **Flash to device** asks for confirmation. It is disabled, with the reason shown, when there's no device, more than one device, or a non-WinUSB driver on Windows.
- **Devices:** live USB detection, polled every 2 s and safe with hotplug. Shows product, serial, bus/address/port, speed and, on Windows, the bound driver (WinUSB = flashable). Buttons: **Dump info to JSON** (saved to `dumps/`) and **Reset session (0x12)**.
- **Update:** **Check catalog** reads Blackmagic's public catalog and marks the versions already indexed. Each version has **Download** (download → extract → inventory → index); extraction needs Windows `msiexec`. There's also **Rebuild index**.
- **Log:** the integrated console. It follows new lines and pauses when you scroll up; **Copy** and **Open file** are in the header. raylib's INFO chatter is hidden and the home folder shows as `~`; the log file and Copy keep every line.

## Readouts
- **Progress panel:** hash check → erase (`Erase A (FPGA): n/144 blocks`) → write (per-image MB plus the total). Closing the window during a flash waits until the flash finishes, and Esc never closes the app.
- **Status bar:** one short line per result, for example `Flashed DV 16.5 · not verified (no read-back) · unplug USB, then power-cycle`. Full error chains go to the log.

## Look and behaviour
- Clay layout with UBMDF's own raylib-6 renderer (`src/gui/render.rs`).
- Resizable portrait window: 600×860 by default, 460×560 minimum.
- Arimo Regular and Bold are bundled, rasterised per size, including Latin-1 and `… — →`.
- Dark/Light theme toggle, remembered in `ubmdf-gui.conf`.
- Device and network work runs on worker threads.
- 60 fps while busy, 15 fps when idle.
- Windows GUI builds use the GUI subsystem, so no console window appears. CLI commands from a terminal still print normally.

## App icon (temporary)
The icon is an UltraStudio-style unit with EBU colour bars (100/0/75/0) on its screen, generated by `tools/make-icon.ps1`:
- `assets/icon/ubmdf.png`, 512 px;
- `assets/icon/ubmdf.ico`, 16–256 px.

To change the art, replace both files and rebuild. Where the icon is used:
- **Windows and Linux:** the PNG is the window icon.
- **macOS:** the Dock icon comes from the `.app` bundle's `.icns`.
- **Windows:** `build.rs` also embeds the `.ico` in the exe.
